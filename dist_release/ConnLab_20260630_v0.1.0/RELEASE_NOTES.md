# ConnLab Release Notes

This portable release is intended for Windows desktop use.

## Requirements

- Microsoft Office is installed.
- Microsoft Edge or Microsoft Edge WebView2 Runtime is available.
- The whole release folder is copied together.

## Startup

Run `ConnLab.exe`.

The application starts its local backend automatically and opens the ConnLab desktop window. No Python, Node, npm, Vite, or manual backend/frontend startup is required on the operator computer.
