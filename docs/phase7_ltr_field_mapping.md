# Phase 7 LTR Field Mapping

Date: 2026-04-28

## Scope

This document covers `TASK_039_LTR_FIELD_CATALOG_AND_READINESS_SOURCE_MAP` only.

It defines the authoritative 19-field LTR readiness catalog used by later readiness, preview, and workbook tasks. It does not implement readiness checks, LTR number generation, workbook read/write, registration preview, or UI behavior.

## Severity Policy

| Severity | Meaning | Registration behavior |
|---|---|---|
| `BLOCKER` | A confirmed value is required before LTR preview or registration. | Block until confirmed. |
| `REVIEW_REQUIRED` | The value can be missing only if the operator confirms an explicit policy. | Require review before registration. |
| `PLACEHOLDER_ALLOWED` | The value is not knowable at registration time. | Use the explicit placeholder policy. |

## Boundary Notes

- The catalog is implemented as pure Python under `backend/modules/ltr/ltr_field_catalog.py`.
- It does not import Excel, SQLite, FastAPI, Office gateways, or settings.
- `Test Result` and `Failed item` are explicitly `PLACEHOLDER_ALLOWED` because they are future-result fields and should not block initial LTR registration.
- Later readiness services may evaluate this catalog, but this task does not implement that evaluation.
