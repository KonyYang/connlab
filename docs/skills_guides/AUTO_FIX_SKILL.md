# ConnLab Auto Fix Skill

当 pytest 测试失败时，必须使用本 Skill 修复。

## 目标

只修复当前测试失败原因，不允许扩展功能，不允许重构无关代码。

## 输入

- pytest 失败日志
- 当前失败测试文件
- 相关源代码文件
- 当前 Task 文件

## 修复原则

1. 先阅读 AGENTS.md
2. 先阅读当前 Task 文件
3. 只分析失败测试对应的代码
4. 只修复导致测试失败的最小代码
5. 不允许新增未要求功能
6. 不允许修改测试来掩盖错误，除非测试本身明显与 Task 要求冲突
7. 不允许进入下一个 Task

## 修复流程

### Step 1：诊断失败原因

必须输出：

- 失败测试名称
- 失败位置
- 根本原因
- 是代码问题、测试问题、环境问题，还是路径/依赖问题

### Step 2：制定最小修复方案

必须输出：

- 要修改哪些文件
- 为什么只改这些文件
- 不会改哪些文件

### Step 3：执行修复

要求：

- 最小修改
- 保持架构分层
- 保持类型标注
- 保持 docstring
- 不破坏已通过测试

### Step 4：再次运行测试

必须建议运行：pytest
或者运行：.\scripts\run_tests.ps1

### Step 5：输出结果

必须包含：

修改文件列表
修复原因
运行测试命令
预期结果
禁止行为
禁止删除失败测试
禁止把 assert 改弱来让测试通过
禁止跳过测试
禁止使用 pytest.mark.skip 掩盖问题
禁止修改无关模块
禁止重写整个项目结构
禁止继续下一个 Task
