# TASK 013 — Minimal Frontend Shell

## Goal

Create a minimal React UI shell for MVP workflows.

## Scope

- Project list page.
- Project detail/workbench page.
- Navigation placeholders for Precheck, LTR, Folder.

## Requirements

- Use TypeScript.
- Keep UI simple and task-driven.
- No menu-toolbar legacy pattern.
- Frontend calls API services through a small client layer.

## Pages

- `/projects`
- `/projects/:id`

## Out of Scope

- No Matrix page.
- No Report page.
- No advanced styling.

## Acceptance Criteria

- User can view project list and project detail from API.
- UI shows MVP task cards: Precheck, LTR, Project Folder.
