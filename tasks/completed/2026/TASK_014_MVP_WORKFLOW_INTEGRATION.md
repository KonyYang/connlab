# TASK 014 — MVP Workflow Integration

## Goal

Connect the full MVP flow through backend and minimal frontend.

## Scope

- New project.
- Upload application form.
- Run precheck.
- Register LTR.
- Preview/generate folder.

## Requirements

- Show project status on workbench.
- Show precheck issues.
- Show LTR status.
- Show folder generation status.
- Keep state transitions explicit.

## Tests

- Backend integration test for full workflow.
- Manual frontend smoke checklist.

## Acceptance Criteria

A lab engineer can complete:

```text
Project -> Application form -> Precheck -> LTR -> Folder
```

without using code.
